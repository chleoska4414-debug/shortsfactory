# 샘플 영상

AI 숏폼 스튜디오가 **자동 생성한** 예시 영상입니다. 모두 프로그램이 생성한
그라데이션 배경 + 한국어 AI 음성(edge-tts) + 음성 싱크 자막으로 조립되었습니다.
저작권 문제가 없는 요소만 사용했습니다.

| 파일 | 버전 | 길이 | 음성 | 주제 |
|---|---|---|---|---|
| `sample_A_아침루틴_32초.mp4` | A (짧고 강렬) | 약 32초 | 여성(SunHi) | 아침 루틴 3가지 |
| `sample_B_물2리터_95초.mp4` | B (완결형) | 약 95초 | 남성(InJoon) | 하루 물 2리터 마시기 |

## 영상 보는 방법
- **GitHub 웹에서**: 파일을 클릭하면 브라우저에서 바로 재생됩니다(소리 포함).
- **다운로드**: 파일 페이지의 **Download** 버튼으로 받아서 재생.

## 참고 (정직한 안내)
- 대본은 현재 무료 템플릿 기반이라 내용이 일반적입니다. LLM API 키를 연결하면
  구체적이고 흥미로운 대본으로 품질이 크게 향상됩니다.
- 이 도구는 수익을 보증하지 않습니다.
