# AI 숏폼 자동 수익화 스튜디오 (Shorts Studio)

얼굴 출연·직접 녹음 없이 AI 중심으로 숏폼(YouTube Shorts / Instagram Reels / TikTok) 영상을
**저작권·플랫폼 정책을 준수하며** 반자동으로 제작·관리하는 로컬 스튜디오입니다.

> ⚠️ 중요: 이 프로젝트는 **수익을 보장하지 않습니다.** 타인 영상의 무단 복제나
> 반전·배속·크롭 등 저작권 탐지 회피 기능을 **구현하지 않습니다.** 권리가 확인된
> 소재만 사용하며, 초기에는 사용자의 최종 승인을 받은 영상만 게시합니다.

## 설계 원칙
1. **라이선스 게이트** — 이용 권한이 확인되지 않은 소재는 제작 파이프라인에 들어올 수 없습니다.
2. **정직한 상태 표시** — 실제로 실행·검증된 기능만 '완료'로 표시합니다.
3. **인간 승인 게이트** — 초기에는 사용자 승인 없이 어떤 영상도 게시되지 않습니다.
4. **무료·오픈소스 우선** — FFmpeg 등 검증된 오픈소스를 우선 사용합니다.
5. **민감정보 분리** — API 키/비밀번호는 `.env`로 관리하며 소스코드에 넣지 않습니다.

## 기술 스택 (예정)
- Python 3.11+
- FastAPI (로컬 대시보드 + API)
- SQLite (데이터 저장)
- FFmpeg (영상 조립)
- Whisper (자막/싱크), 오픈소스 TTS, LLM API (대본)

## 개발 단계
MVP(권리DB → 소재수집 → 영상1편 자동제작 → 미리보기) → 품질검수 → 트렌드분석 → 업로드 → 성과분석

자세한 요구사항/설계/작업은 `.kiro/specs/shorts-studio/` 를 참고하세요.

## 실행 방법 (로컬)
```bash
python -m venv .venv
. .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install edge-tts         # 무료 한국어 TTS
# FFmpeg 설치 필요 (Windows: 공식 빌드 PATH 등록, 또는 .tools/ 에 배치)
python run.py                # http://127.0.0.1:8000
```

## 현재 상태 (MVP 동작 — 실제 검증됨)
- ✅ 저작권 판정 엔진 (CC 매트릭스, 미확인=불가, 만료 처리) — 단위테스트 통과
- ✅ 소재 관리 + 라이선스 게이트 (권리 미확인 소재 자동 제외)
- ✅ 영상 1편 자동 제작: 대본 → 한국어 TTS → 자막 싱크 → FFmpeg 조립 (9:16, 1080×1920, H.264 MP4)
- ✅ 한국어 대시보드: 소재 등록 / 영상 제작 / 미리보기 / 승인 / 시스템 상태
- ✅ 테스트 30개 통과

### 아직 미구현 (정직한 표시)

- B 버전 목표 길이(65~90초) 도달(현재 템플릿 대본이 짧음)
- 소재 파일 업로드 UI(현재 경로 입력)
